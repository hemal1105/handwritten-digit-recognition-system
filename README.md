# Handwritten Digit Recognition System

A web-based handwritten digit recognition system built using Flask and TensorFlow CNN trained on the MNIST dataset.

## Features
- Draw a digit on canvas
- Upload digit image
- Predict digits (0–9)
- CNN-based classification

## Technologies Used
- Python
- Flask
- TensorFlow/Keras
- HTML
- CSS
- JavaScript

## Run Locally

pip install -r requirements.txt
python app.py

Open:
http://127.0.0.1:5000
